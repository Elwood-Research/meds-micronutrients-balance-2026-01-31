# Reference Notes

## NHANES-focused micronutrient and function studies
- Orces 2019 (10.20960/nh.2507): NHANES 2007--2014; serum 25(OH)D by physical disability status in older adults; supports vitamin D status--function link.
- Kalenkoski 2020 (10.1007/s12062-020-09291-6): NHANES; vitamin D, cognition, and gait speed; provides NHANES gait-speed outcome for vitamin D.
- Kositsawat 2022 (10.1007/s00223-022-01037-0): NHANES; homocysteine associated with gait speed and strength; B12-related metabolic pathway.
- Ji 2023 (10.3390/antiox12030619): NHANES 2011--2018; serum folate inversely related to functional disability domains.

## Vitamin D and physical performance/balance
- Moon 2019 (10.4235/agmr.19.0002): Community-dwelling older adults; 25(OH)D associated with physical performance tests.
- Shardell 2015 (10.1093/gerona/glv017): InCHIANTI; vitamin D and lower-extremity performance; biomarker context.
- Kositsawat 2019 (10.1093/gerona/glz165): InCHIANTI; vitamin D x IL-6 interaction on slow gait speed.

## Vitamin B12/folate and physical function
- Vidoni 2017 (10.1007/s12603-017-0893-4): B12 and homocysteine associated with gait speed in older adults.
- Ng 2012 (10.3945/ajcn.112.035741): Folate, B12, homocysteine linked to physical function in aging cohort.
- Dokuzlar 2017 (10.14744/nci.2017.82787): Serum B12 levels associated with frailty.

## Medication burden / polypharmacy and function
- Katsimpris 2019 (10.1007/s11606-019-05106-3): Systematic review; polypharmacy associated with lower physical function.
- Abu Bakar 2021 (10.3390/ijerph18168257): Polypharmacy linked to falls; balance/gait assessed with POMA.
- Salkin 2025 (10.18678/dtfd.1585896): Polypharmacy associated with poorer balance (BBS) and mobility (TUG).
- Roman de Mettelinge 2013 (10.1371/journal.pone.0067055): Medication count mediates diabetes--falls associations; gait/balance measures included.

## Physical performance/balance outcome context
- Talkowski 2008 (10.2522/ptj.20080036): Balance performance and gait speed relate to walking activity.
- Studenski 2011 (10.1001/jama.2010.1923): Gait speed predicts survival; supports clinical importance of gait-speed outcome.
