# Study: Medication burden, micronutrients, and balance

## Research question
Among older adults, how does medication burden (count of prescriptions) interact with micronutrient status (vitamin D, vitamin B12, folate) to predict physical performance and balance?

## Objectives
- Quantify associations between prescription count and physical performance and balance outcomes.
- Evaluate main effects of serum vitamin D, vitamin B12, and folate on outcomes.
- Test interaction terms between medication burden and each micronutrient for effect modification.

## Population
- Older adults (target age cutoff to be set during data review; default 60+).
